# Misinformed: PvP and PvM Tracker

**Author:** Ybc

Misinformed is a RuneLite plugin for tracking your personal PvP and PvM sessions from one clean sidebar. It combines PvP statistics, PvM loot tracking, valuable drops, collection log unlocks, session goals, recent activity, configurable overlays, and share-ready summaries.

## Features

### PvP Tracking
- Tracks PvP kills during the current session.
- Tracks PvP deaths while in PvP areas.
- Calculates your session K/D ratio.
- Tracks total PvP loot.
- Tracks your biggest PK of the session.

### PvM Tracking
- Tracks NPC kills during the current session.
- Tracks total PvM loot.
- Tracks your best PvM drop.
- Counts valuable drops using your configured value threshold.

### Valuable Drops
- Configurable GP threshold for valuable drops.
- Valuable drops appear in Recent Activity.
- Optional RuneLite notifications.
- **Copy Latest** creates a share-ready summary of the latest notable drop.

### Collection Log
- Detects new collection log unlock messages.
- Adds unlocks to Recent Activity.
- Optional RuneLite notifications.
- **Copy Latest** can copy the latest collection log unlock.

### Session Dashboard
- Full-width RuneLite sidebar layout.
- Separate PvP and PvM sections.
- Live session timer.
- Personal challenge progress bars.
- Recent Activity feed.
- **Copy Summary**, **Copy Latest**, and **Reset Session** controls.

### Personal Challenges
- Configurable PvP kill goal.
- Configurable PvM kill goal.
- Progress updates throughout the session.

### Customisable Overlay
Each overlay section can be enabled or disabled independently:
- Session timer.
- PvP kills, deaths and K/D.
- PvP loot and biggest PK.
- PvM kills.
- PvM loot and best drop.
- Challenge progress.
- Entire overlay.

This allows PvP-only, PvM-only, or mixed overlay layouts.

### Sharing
- **Copy Summary** copies the complete current session.
- **Copy Latest** copies the latest notable PvP kill, valuable drop, or collection log unlock.
- Paste copied summaries into Discord, clan chat, messages, or anywhere else.

### Configuration
- Toggle PvP tracking.
- Toggle PvM tracking.
- Configure individual overlay elements.
- Configure valuable-drop threshold.
- Toggle valuable-drop notifications.
- Toggle collection-log tracking and notifications.
- Configure PvP and PvM challenge goals.

## Usage

1. Enable **Misinformed: PvP and PvM Tracker** in RuneLite.
2. Open **Misinformed** from the RuneLite sidebar.
3. Configure the tracking and overlay elements you want.
4. Play normally while the plugin tracks your session.
5. Use **Copy Summary** or **Copy Latest** when you want to share results.
6. Use **Reset Session** when you want to begin a fresh session.
